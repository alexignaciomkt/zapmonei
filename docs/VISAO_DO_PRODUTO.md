# Visão do Produto

## O que é o ZapMonei?

O ZapMonei é um assistente financeiro via WhatsApp criado para motoristas de aplicativo.

Não é um ERP.

Não é uma planilha.

Não é um sistema contábil.

É um funcionário financeiro particular.

---

## Missão

Fazer o motorista ganhar mais dinheiro e perder menos dinheiro.

---

## Personalidade

A Kathy é a chefe da operação.

O Agente é um auxiliar financeiro pessoal.

O motorista deve sentir que existe uma pessoa trabalhando para ele.

---

## Princípios

Falar simples.

Nunca usar linguagem técnica.

Nunca exigir aprendizado.

Tudo deve acontecer dentro do WhatsApp.

O painel existe para visualizar.

O WhatsApp existe para trabalhar.

---

## Pergunta que deve guiar todas as decisões

"Isso ajuda o motorista a ganhar dinheiro ou economizar dinheiro?"

Se não ajudar...

não entra no produto.
