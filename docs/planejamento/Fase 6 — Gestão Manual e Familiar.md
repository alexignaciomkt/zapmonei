# Fase 6: Gestão Manual e Familiar

Esta fase expande o ZapMonei além do WhatsApp, transformando-o em uma ferramenta completa de gestão financeira doméstica e profissional.

## 🛠️ Tecnologias
- **Frontend:** React Hook Form + Zod (Validação).
- **Storage:** Supabase Storage para fotos de recibos via Web.
- **Integração:** Webhook de OCR compartilhado com o WhatsApp.

## 📋 Funcionalidades Implementadas
1. **Lançamento Manual Híbrido:**
   - Formulário para inserção rápida de dados financeiros diretamente pelo Painel.
   - Suporte a upload de imagens de recibos (notas fiscais, cupons de postos, etc).
2. **Processamento Inteligente (Web OCR):** 
   - Ao subir uma imagem no Painel, o sistema pode acionar a mesma Engine de IA (Gemini Vision) para preencher automaticamente os campos de valor e categoria.
3. **Multi-Dispositivo / Multi-Usuário:**
   - O Dashboard é otimizado para que o motorista e sua esposa possam usar simultaneamente em dispositivos diferentes.
   - Compartilhamento simples via Magic Link.
4. **Categorias Customizáveis:** Interface para que a família crie categorias específicas para sua realidade (ex: "Escola", "Lazer", "Investimentos").

## 🎯 Objetivo de Branding
Posicionar o ZapMonei como o **Centro de Comando Financeiro da Família**. Ele resolve a dor do motorista na rua, mas também organiza a economia da casa, unindo todos em um único objetivo de crescimento.
