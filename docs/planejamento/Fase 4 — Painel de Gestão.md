# Fase 4: Dashboard Web & PWA

A interface visual para a reflexão estratégica do motorista. No Zap ele registra, aqui ele analisa e cresce.

## 🛠️ Tecnologias
- **Frontend:** Next.js 15+ (App Router).
- **Estilização:** Tailwind CSS v4 com Glassmorphism.
- **Gráficos:** Recharts.
- **Animações:** Framer Motion.

## 📋 Funcionalidades Implementadas
1. **Design Cockpit:** Visual Dark Mode de alto contraste, otimizado para leitura sob luz solar forte.
2. **Dashboard de Performance:**
   - **Lucro Líquido Real:** O valor que sobra após todos os custos (combustível, taxas, manutenção).
   - **Indicador de Saúde Financeira:** Barra visual comparando Ganhos vs. Gastos.
3. **PWA (Progressive Web App):** Capacidade de instalar o painel na tela inicial do celular como um aplicativo nativo.
4. **Histórico Inteligente:** Listagem cronológica dos lançamentos feitos via WhatsApp, permitindo conferência e edições rápidas.
5. **Mobile-First:** Experiência de uso otimizada para toques rápidos entre corridas.

## 🎯 Objetivo de Branding
Demonstrar o **profissionalismo e a clareza**. O Dashboard dá ao motorista a visão de "Dono de Empresa", ajudando-o a tomar decisões melhores sobre o seu tempo e dinheiro.
